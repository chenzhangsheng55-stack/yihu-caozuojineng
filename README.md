# 医护操作技能 · 随机模拟测验

《医护知识 · 操作技能》6 个技能、12 个单元的手机端模拟测验，每次进入自动抽一套新卷，并按技能/单元累计统计错误率。

**在线地址：https://chenzhangsheng55-stack.github.io/yihu-caozuojineng/**

交卷后立即出分，逐题显示对错、正确答案与解析，可切换"只看错题"。等级：80 分及以上 A、60～79 分 B、60 分以下 C。

## 错题统计（按技能 / 单元）

- 每次交卷，把每道**作答过**的题记一次"做过"，答错再记一次"做错"（未作答的不计入，免得超时交卷把错误率拉高；填空题有一个空错就算错）。
- 首页「薄弱模块 · 累计错误率」：按 6 个技能分组列出 12 个单元的累计错误率与做题数，顶部标出错误率最高的 3 个单元（至少做过 3 题才参与排名）。
- 成绩页「本卷各单元错题」：这一套里每个单元错了几道。
- 「错题本」：所有做错过的题按**累计做错次数**从多到少排列，可按技能筛选，附正确答案和解析，用来重背。
- 「清空统计」只清错题统计，不影响成绩记录和抽题进度。

统计存在本机浏览器 `localStorage`（键名前缀 `czjn_`），换手机或换浏览器不会同步；清除浏览器数据会一起清掉。

## 限时与防作弊

- 全卷限时 **60 分钟**，剩 5 分钟转红，归零自动交卷。时长改 `site/index.html` 里的 `EXAM_MINUTES`。
- 离开答题界面（切应用、锁屏、切标签页、搜题悬浮窗/分屏抢焦点）即计次，**累计 2 次自动交卷**。
- 题干与选项禁止选中、复制、右键（填空输入框不受影响）。
- 截屏 OCR 型悬浮窗不抢焦点、不隐藏页面，网页探测不到，对它起作用的是限时。

## 抽题规则

题库洗成一副牌顺序取题，**走完整副才重洗**：选择题 367 道 → 连做 7 套不撞题；填空题 70 道 → 7 套不撞题。选项顺序每次重新打乱。

## 怎么加题

题库按单元组织，每个单元一段 `push({c:技能, u:单元, items:[...]})`。

选择题，**正确答案写在第一个**，组卷时自动打乱：

```js
["题干", ["正确答案","干扰项","干扰项","干扰项","干扰项"], "解析"],
```

填空题，`____`（四个下划线）为空位，每题最多 2 个空，同一空的多种写法都列进去（数字题会自动忽略单位、℃、%、全半角和 ~/-/至 的差异）：

```js
["发热的定义：腋下温度＞____℃或口腔温度≥____℃。", [["37"],["37.3"]]],
```

新增单元就加一段 `push`；新增题库文件再在 `index.html` 里加一行 `<script src>`。改了题干会被当成新题重新统计。

## 部署

推送到 `main` 即自动部署（`.github/workflows/deploy.yml`）：先跑 `node scripts/check_bank.js`（选项、空位数、标准答案能否被判对），通过后发布 `site/`；不通过则不发布，线上保持上一个可用版本。
